# Caso de estudio: Predicción de rotación de empleados

**Asignatura:** Introducción a Machine Learning – Universidad de Cundinamarca
**Autor:** Harold Steven Rueda Lara

## Descripción
Implementación de Regresión Logística y modelos de clasificación supervisada para predecir si un empleado renunciará (1) o permanecerá (0) en la empresa, a partir de edad, salario, años en la empresa, nivel de satisfacción y horas extra.

## Contenido
- `Caso_Rotacion_Empleados_RRHH.ipynb`: notebook desarrollado en Google Colab.

## Modelos
Regresión Logística, Árbol de Decisión, Random Forest, KNN, SVM y Naive Bayes.

## Métricas
Accuracy, precisión, recall, F1-score, matriz de confusión, reporte de clasificación y validación cruzada.

## Librerías
NumPy, Pandas, Matplotlib y Scikit-learn.

## Cómo ejecutarlo
1. Abrir el notebook en [Google Colab](https://colab.research.google.com) (Archivo → Abrir cuaderno → GitHub).
2. Ejecutar todas las celdas (Entorno de ejecución → Ejecutar todo).
